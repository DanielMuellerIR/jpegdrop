JPEGdrop — drop images, keep the originals.

Drag JPEGdrop to Applications, then open it. It includes its own runtime;
Python and Homebrew are not required. Choose the output codec and preset
from the JD menu, then drop images onto the app's Dock or Finder icon.
Metadata-free copies are saved beside the originals. Source files stay unchanged.

Requires Apple Silicon. Declared runtime minimum: macOS 12.0; release testing
has been performed on current macOS. See the release notes for tested versions.

Updates: JPEGdrop menu → Nach Updates suchen…
Automatic checks can be disabled in Settings. Updates require confirmation
and wait for active conversion jobs. Privacy details are available from the app menu.

Help: https://github.com/danielmuellerir/jpegdrop
Third-party notices: Licenses folder and the app's Contents/Resources/Licenses.

Deutsch

JPEGdrop nach Programme ziehen und öffnen. Python oder Homebrew sind nicht nötig.
Im JD-Menü Codec und Preset wählen, dann Bilder auf das Dock- oder Finder-Icon
ziehen. Metadatenfreie Kopien entstehen neben den unveränderten Originalen.

Voraussetzung: Apple Silicon. Technische Mindestversion: macOS 12.0;
Release-Tests laufen auf aktuellem macOS. Getestete Versionen stehen in den Release Notes.

Updates: JPEGdrop-Menü → Nach Updates suchen…
Automatische Prüfungen lassen sich in den Einstellungen ausschalten.
Die Installation erfordert eine Bestätigung und wartet auf aktive Aufträge.
Datenschutzhinweise stehen im App-Menü, Lizenztexte im Ordner Licenses.
