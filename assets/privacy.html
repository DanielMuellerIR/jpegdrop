JPEGdrop: Datenschutz

JPEGdrop verarbeitet Bilder lokal. Bilder, Dateinamen, Ergebnisse und Einstellungen werden nicht hochgeladen. Es gibt keine Analyse- oder Absturzmeldedienste.

Eingebettete EXIF-/GPS-/ICC-Daten werden nach der Orientierungs- und Farbumrechnung entfernt. Dateinamen, Dateisystem-Zeitstempel und sichtbare Bildinhalte werden nicht anonymisiert.

Bildoptionen und gewählte Ausgabepfade liegen unter ~/Library/Application Support/JPEGdrop/settings.json, Update-Einstellungen in den macOS-Einstellungen der App. Die Auftragsliste bleibt nur für die Sitzung im Speicher. Erzeugte Bilder liegen in der gewählten Ablage. Private temporäre Dateilisten werden beim regulären Abschluss gelöscht; ein harter Abbruch kann Listenreste hinterlassen.

Update-Prüfungen

Automatische und manuelle Update-Prüfungen laden den Feed von GitHub Pages. Nach Bestätigung wird das Update von GitHub Releases geladen. GitHub erhält technische Verbindungsdaten wie IP-Adresse und User-Agent. Die Übermittlung eines Systemprofils ist ausgeschaltet.

Automatische Prüfungen lassen sich in den Einstellungen ausschalten; die manuelle Suche bleibt möglich. Die Installation erfordert eine Bestätigung.

Privacy

JPEGdrop converts images locally. It does not upload images, filenames, results or settings, and has no analytics or crash-reporting service. Embedded EXIF/GPS/ICC metadata is removed after orientation and color conversion. Filenames, filesystem timestamps and visible image contents are not anonymized.

Image options and chosen output paths are stored in ~/Library/Application Support/JPEGdrop/settings.json. Update preferences use macOS app preferences. The job list stays in memory for the current session; generated files remain in the selected output location. Private temporary file lists are removed at normal completion; a forced termination can leave temporary lists.

Automatic and manual update checks contact GitHub Pages. Confirmed updates download from GitHub Releases. GitHub receives connection information such as your IP address and the update client's user agent. System profile submission is disabled. Automatic checks can be disabled in Settings. Installation requires confirmation.

See the linked GitHub privacy statement and publisher's legal/privacy information for contact details and rights.
